# 开发预览基础示例

本页与两张示例卡由 PAA 项目在 2026-10-08 为公开开发预览编写，Agent 辅助，按 CC BY 4.0 提供。它没有课程或视频来源，不代表任何第三方作者的观点。

## PK001：把参考关系放回当前条件

看到可借鉴的画面时，先说明可见的主体、背景、光线和空间关系。然后对照当前场地、人物、器材和可调整位置，选择一项能够尝试的关系，做小样比较。相似检索只负责提供候选，实际效果要由查看图片和现场条件判断。不要把图像外观当作真实 EXIF 或作者心理的证据。

## PK002：用稳定编号继续指图

在展示参考图时，保存展示编号到 asset_id 的对应。后续提到同一张图片，用 get_image 重新取得它并查看当前 context。遇到图片被替换、身份校验不符或不可读取时说明变化，不猜一个相近文件替代。只有 Agent 实际接收到图像内容才算看图；文件路径和工具成功消息不能单独证明看图完成。

具体图片分析仍按当前问题自由观察，不要求每次使用这两张卡。维护 annotation 时保留使用者的前文和其他字段，只处理当次明确授权的素材。
