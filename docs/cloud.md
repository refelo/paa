# 云端代码的当前范围

仓库保留只读业务服务、内容哈希同步、导入、续接与部署相关源码，便于以后在独立环境继续研究。首版支持目标是 Windows＋Codex 本机，不承诺已有从空服务器安装的公开流程。

没有附带任何真实连接配置、域名、服务器身份、认证凭据、私有预览签名、原图库或部署记录。不得自动寻找、复制或连接另一个实例的 `.local/cloud`，也不得因为源码存在就创建或购买服务。

后续另行开展云端任务时，需重新确定实例身份、资料范围、认证与传输、服务器环境、费用和验收；复制原图到远端与代码公开是不同许可。原课程视频与字幕不默认成为云端检索材料。

本机维护默认不请求云端；仅显式 --cloud 才检查本实例连接配置。验证范围见[接手状态](../PROJECT_STATUS.md)。
