# 本机增量维护与恢复

这页说明继承的维护接口；需要先完成当前实例安装和使用者授权。初始公共基线不包含有效生产配置，当前不执行真实资料维护。

## 当前可用接口

```powershell
python -m paa doctor --summary
python -m paa maintain plan
python -m paa maintain run
python -m paa maintain status --run <运行ID>
python -m paa maintain resume --run <运行ID>
```

`run` 默认仅本机，`--local-only` 仍可显式使用。只有 `--cloud` 请求同步；缺少本工作区的 `.local/cloud/connection.json` 时在创建运行前失败。`resume` 沿用原记录，包括旧记录已经选择的云端范围，不擅自改选项。

新安装的 `maintenance_vectors=false` 表示本轮不请求图片和卡片向量构建，回执为 `not_requested`，不宣称向量已完成。另行获准素材范围、费用并配置预算后，才启用此项或显式运行 index/cards-index。旧配置没有此字段时继续原索引流程；离线缓存不足会真实失败。没有图片库时可用知识检索，图片维护会提示先选择图库。

`plan` 检查变化；`run` 冻结图片 ID、内容哈希和已登记课程。`needs_agent` 表示还需实际看图、完整读文和语义判断，Agent 完成任务后才能续接。新图、内容替换图或缺 AI 段才分配备注；人工字段变化不应强制重写旧 AI 分析或重算图片向量。

模型、预处理配方和内容匹配才复用向量。执行中新增加的图片留待后续；冻结对象被替换时停止，不能套用旧观察。无付费许可可复用缓存，缺必要向量时明确阻断或在查询中报告真实降级。

## 课程与知识

资料根目录只由使用者明确登记，不扫描下载盘。已有字幕按身份复用，正文必须完整进入上下文；采样画面必须实际查看，不能说成连续看完视频。空字幕但有图像的来源按实际视觉分析登记，不能只凭转写完成标为蒸馏完成。

卡片先雏形后归并，技巧与个人观点分开，详细见[卡片方法](card-maintenance.md)和[V2 接口](distillation-v2.md)。不从其他实例导入旧“已完成”队列或历史许可。汇编更新范围由使用者确定，不能因单卡小改自动重做全部内容。

## 恢复与完成

以一次运行返回的 record 和 progress 为准。先确认旧写入进程已经结束，再核对不确定项，保留已完成回执；不通过清空范围或抢锁来重跑。写入成功数量不等于全库内容质量审查，卡片源件与用户人工信息始终保留。

云端同步、部署和回退代码仍在仓库，但[云端范围](cloud.md)明确为后续选项，本机初版不连接私人服务器。
