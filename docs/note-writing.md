# 图片观察与备注写作

这份方法用于专门看图、撰写可供以后找图的 AI 备注。日常讨论与策划由 Agent 自主组织，不要求回答套五个栏目。

## 开始前

实际查看每张图，并读取同图现有人工信息。旧备注、路径、工具成功或“已看”声明都不能替代接收图像。GIF 使用可取得的代表帧；拼图分清画格和对象。不可读图片如实留待处理。

先读本方法、[词表](note-vocabulary.json)及[基础技巧汇编](../knowledge/core/compilation.md)。知识提供观察视角，不限制独立判断。作者观点只在使用者明确选择启用时按需取用；用户自己的参考卡可以不存在，不能用公开作者观点代填。

长材料分段读，截断处补齐；已有效读过的内容不为保险反复读。上下文压缩后补回丢失的必要方法并继续原分配，不重做已确认完成项。

星级、标签及反向标记的含义由各使用者说明，不能继承另一人的约定。人工标记提示关注点，不穷尽图像价值；AI 正文不复述星级、不扩写用户原意，也不将观察冒充用户意见。可见事实、器材初判、作者观点与创作联想用自然措辞分清。

## 固定核心在前，自由观察在后

每张图显式写出以下五个核心，再写自由观察。具体描述应当相互补充，同一元素不在每栏反复介绍。媒介明确时自然点明摄影、插画、漫画或混合画面；不猜生成工具。

### 1. 焦段预测

每个摄影画面都给出猜测的全画幅等效焦段数值范围，并写简明依据，例如：

> 焦段预测（全图）：约 28–50mm（全画幅等效）；近处手臂有一定放大，人物与环境仍保持明显距离层次，虚化较轻。

依据综合透视、近远比例、视野、主体与背景距离感和虚化。虚化不能单独决定焦段；拍摄距离、光圈、画幅、裁切和合成都可能改变观感。不能因无法证明真实镜头而省略有用推测；线索弱可宽估，解释具体原因，不机械给所有照片同一个宽范围。

起始参考档由本方法划定，便于表达，不是测量精度或光学定律：

| 范围 | 观感参考 |
|---|---|
| 14–24mm | 超广角 |
| 24–40mm | 广角 |
| 40–65mm | 标准 |
| 65–105mm | 中长焦 |
| 105–200mm | 长焦 |
| 200mm 以上 | 更长焦 |

允许跨档范围，如 28–50、35–85、50–105mm，以图片依据为准。不得把“范围覆盖 35mm”写成“确定使用 35mm”；也不需要额外贴互斥的 35mm/85mm 观感标签。

多格摄影分别写“焦段预测（上图）”“焦段预测（下图）”等，不平均不同机位。插画可推测模拟镜头范围；透视混合、错误或参照不足时允许“不确定”，并说明实际原因。纯平面设计不编造相机，写“不确定／无统一相机空间”；含摄影底图时，可对底图另作范围初判。

### 2. 光线分析

主动分析画面有哪些方向的光、可能的主光与补光、光源性质、柔硬、相对强弱和光比。先给可见依据，再提出初步判断；例如鼻影、投影、发边、眼中反光、材质高光和环境来光。用户需要据此理解和把控光，不要只说“左亮右暗”，也不要以无法确认器材为由回避有依据的光源假设。

方向以当前画面坐标说明，结合人物朝向说侧前、侧后；旋转图像可以改用“头顶侧后”等相对方向。可写“左上侧前方像大面积窗光，右侧暗面有较弱环境反射补光”。多个亮区不等于多盏灯；同一大光源与环境反射也会共同作用。没有依据时不编灯数、型号、功率。

柔硬根据影缘、明暗过渡和反射形态判断，与全图反差分开。光比优先指主体相近材质的亮侧/暗侧关系，或主光与填充贡献，通常用低、中、高或中低、中高的观感说明。主体明亮、背景很暗是另一种画面反差，不能单凭黑头发、深背景或衣服颜色判主体高光比。无法判断主体光比时说明原因，并保留其他可用的来光判断；不要在查找头同时硬贴高/低光比。无可靠测量来源时不捏造精确比值。

插画可描述“画面设定的来光像……”。没有统一写实布光的平面图，说明明暗由设计色块组织即可。

### 3. 风格与表现

先概括有依据的风格、影调或质感，再说明哪里体现、如何实现、是否混合。例如胶片质感、日系高调人像、青橙色调、赛璐璐式、厚涂、印象派式笔触；没有合适流派名，也应给出具体可用的外观描述。

定位到色调、颗粒、边缘、笔触、造型、对比和部位。人物与背景风格不同就分别说；脸精细、衣物概括、环境松散等刻画分配是证据，不能代替整体风格分析。摄影的透视和虚化主要支持焦段判断，也可在这里说明它们怎样参与成像风格，避免重复罗列。

胶片质感不证明实拍胶片，未见颗粒不硬写颗粒；高调不自动等于柔光；日系风格不由人物身份判断。厚涂、赛璐璐、印象派式等必须有相应表现证据，不因颜色丰富就贴流派。平面设计突出时保留字形、色块、图文与版面关系；密集细节不等于平面设计。

### 4. 视觉组织

把色彩、形组、负空间、疏密和视线引导结合起来，分析画面重心怎样形成。多个元素先看成组，与空白并置；说明组块大小、位置、视角、前后层级和方向怎样建立平衡、偏置或张力，避免逐件清点。

保留主色、辅色、点缀的面积关系、位置和归属：红色在人物还是背景，少量鲜色是否吸引注意，最大色块是否真的承担重心。结合明暗、清晰度和边缘，写清视线起点、引导路径、停点、竞争或回流。

颜色相同、轮廓重复、节奏间隔主要在这里描述。镜像、投影等可说明具体空间和明暗关系；只有进一步产生对视、疏离、主题呼应等意义时，再在下一栏展开。

### 5. 情境与关系

先写实际可见的交互：人与人、人与物、物与物如何接触、支撑、递接、遮挡、指向、相互影响，动势与静止怎样分配。不能把“互动”缩成人际关系，也不要用物品清单代替关系。

再看元素的默认搭配、共同语境、反差与意象联想。例如圣诞树、节庆服装与红绿礼物共同建立节庆情境，意义不限于红绿配色；花与杯可以让人联想到把春日收在掌中。用“让人想到”“可读作”“可以借作”承接有依据的联想，不当作作者唯一意图或人物真实心理。

视觉组织解释元素怎样组成画面；这里解释交互、搭配或反差怎样形成情境和共感。只有色形重复、没有进一步关系时，不强加故事；没有人物同样可以分析物体关系或环境状态。

## 突出时补充的方向

每图都查看五核心；其他方向根据具体价值展开，不另造二十个必填栏。平面设计与图文组织、特殊取景与裁切、图底关系与选择性隐藏、跨画格对应、材质透明与遮挡、明显运动或时间线索等，在特别突出时写入最相关核心或另起短段。研究目录不构成上限；图片中独立有用的新观察仍应保留。

## 自由观察要更充分

明确鼓励多看、多想、多写，使这一部分有独立阅读价值。不要默认用一句“可借鉴……”结束。可以展开核心中尚未讲透的关联、不同读法、微妙细节、表达张力、跨媒介启发、具体取舍，以及改变某一关系会产生怎样的效果，写成相互连接的自然段。

允许比核心部分更充分，允许多段，不设字数或段数上下限，也不用长度打分。信息少的图不凑字，内容丰富的图不主动压成一句。避免复述五核心、泛用建议和无依据寓意；具体不确定影响用途时再说明，不堆免责声明。

例如，只有“可借鉴构图和配色”没有提供新的观察；若画面确有依据，可进一步说明“人物朝向右侧，而左侧亮色空区牵引视线，形成离开与回望的张力；缩小那块亮区会让注意更集中，但减弱这种拉扯”。这是从具体关系解释取舍的示例，不是每图套用的句式。头发、衣摆等方向不同就分别定位描述，不为统一动势写成彼此矛盾的结论；查找头同样按实际成立的对象和画格选词。这些提醒融入正常写作，不另设逐图复审。

## 辅助查找用词

[共用词表](note-vocabulary.json)是唯一正式措辞表，按概念分组并说明别称与边界。它提供入口，不是必须填满的栏目，不以词的数量限制观察范围。自由正文不限定用词；新增有价值关系可自然写清，由主代理判断是否需要调整词表。

开头可写肯定成立的有用短语：

> 辅助查找（全图）：暖色主导；大面积留白；侧逆光。
> 辅助查找（全图·人物）：赛璐璐式。
> 辅助查找（全图·环境）：印象派式笔触。

格式示意不表示这些特征应在同图出现。多格用“上图”“下图”等；多对象需要时写“全图·左侧人物”“上图·背景”等具体范围。正文明确表达且词表有入口的有用关系，可进入对应范围的查找头；不为未成立、否定或无法判断的特征贴肯定词。光源词是初判，风格词是外观分析，主题意象词是有依据的解读，含义不同。

写清颜色属于谁、清楚或模糊的是谁、关系在哪一格，不能把不同人物或画格的属性拼成同一条件。呼应、映照、对比按词表含义分别用，不合成万能关键词。未写到不表示图中没有。

这些是写作约定。当前 MCP 仍用向量/文字入口，尚未实现数值焦段区间或对象范围的严格解析；文字命中不证明所有条件成立。下游 Agent 按需要选词、扩大候选并实际看图判断，不能声称写了规范词就具备精确筛选能力。写作方法本身不提供额外解析算法，也不要求兼容旧 AI 措辞。


## 草稿和写回

单张草稿使用本次取得的完整 `asset_id` 与 `body`；body 不含“【ai生成】”分隔符。批量分配、续接与输入格式见[批量方法](note-batch.md)。模型、批量、并发按当次用户与运行条件决定，不绑定项目作者的安排。

仅在获准的维护任务中，通过 Eagle 官方接口修改 annotation。人工原文留在前，空行后整体替换 AI 段；标签、星级、标注、原图与文件夹保留。写入前后核对当前图库和实际返回，不确定时先核对原写入结果，避免重复写。

普通检索不写备注。素材替换、ID失效或当前库不符时不能把旧观察套到新图；不可读或失败不计完成。图像分析不设打分平台，方法改进用代表案例和回读。
