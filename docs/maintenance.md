# 开发、验证与维护边界

先读[接手状态](../PROJECT_STATUS.md)。本仓库是独立初始化基线，运行数据只放自己的 `.local/`，不通过全局 PAA 借用其他实例。

## 代码和依赖

`paa/` 是 Python 实现；本机 MCP 通过 stdio 使用同一核心。`cloud`、`media` 是可选依赖，普通本机使用不要求服务器或转写模型。项目当前仅保留 Voyage 向量路线；网络和费用由当前使用者配置，不携带作者的许可。

`scripts/manage_install.py` 已改为显式隔离目标的 install/recover/status 入口，替换旧全局注册逻辑。运行 wheel 以源码内容摘要标识，安装前版本和资料保存在本实例恢复记录中；不要求为测试提交开发代码。暂不开放真实用户全局安装，操作见[安装指引](installation.md)。

## 隔离检查

使用已有兼容 Python，在本仓库 `.local/` 下准备测试数据根与临时目录，显式设置 `PAA_WORKSPACE`。继承测试用合成图片、临时卡库、模拟 Provider 与服务；执行前核对测试写入范围。无网络用例不应访问任何真实模型或 SSH。

推荐通过 `python scripts/check_isolated_tests.py` 运行继承回归：脚本设置独立数据和临时目录，禁止网络并约束测试写入及 Git 子进程。它只运行测试，不安装或注册实例。静态检查使用 `python -m ruff check paa scripts tests`。卡片候选的 V2 格式可直接用 `paa.cards.validate` 检查；这不是把它导入生产卡库。

CLI、独立 MCP、真实 Codex 连接与用户看见图片是不同证据。源码版本、通过数量与相似度分数都不能替代真实命中质量。修复可复现代码问题时补最近的行为回归，文档/提示词用回读和相关例子。
