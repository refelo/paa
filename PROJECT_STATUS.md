# v0.0.1 development preview

This is a project-scoped Windows + Codex preview, not a production release.
Python 3.14 is the tested runtime. See README.md and docs/installation.md.

The release ships two original project knowledge examples and no third-party
author preference package. Install choices remain supported and are retained
across updates. Absence of personal preferences does not prevent normal use.

CI uses synthetic data. Real images, account configuration, local test results,
private source candidates and development history are excluded from this export.
The published release notes identify the exact checks completed for the release.
