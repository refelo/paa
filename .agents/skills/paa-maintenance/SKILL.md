# PAA 维护

先核对 [项目状态](../../../PROJECT_STATUS.md)、实例路径和当次资料范围。只维护当前使用者明确授权的实例，不借用其他实例的批次、索引或历史。

按需读[维护流程](../../../docs/automation.md)、[维护说明](../../../docs/maintenance.md)、[图片方法](../../../docs/note-writing.md)和[卡片方法](../../../docs/card-maintenance.md)。maintain run 默认本机；--cloud 需要显式请求及本实例配置。未请求向量构建的回执不能称为索引完成。

Agent 实际看图、完整接收指定文本并作语义判断；工具负责冻结范围、保存、增量、去重和恢复。命令完成不代表语义完成。个人审美包只按安装者明确选择取用，不从可选目录补读被拒绝内容。

备注只写 annotation，保留人工前文和其他字段。同一图 ID 同时只有一个写者。并行需要当次明确安排，不照搬过去的模型、并发或批次大小；操作见[批量说明](../../../docs/note-batch.md)。未获新的范围许可，不把过程中新增素材算入原批次。

技巧与作者观点分开；新知识经过完整阅读、雏形与阶段归并，保留真实条件与分歧。原课程只读归档，当前卡库不携带其他人的历史与来源映射。汇编和个人参考的更新范围由本实例使用者决定，不继承项目作者的自动更新授权。

恢复时复用已有范围与完成回执，先确认旧进程结束，不能抢锁或将失败记成功。只记录必要进度，避免重复输出全库；新增付费调用、真实服务或公开发布按对应任务许可。
