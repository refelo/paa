# PAA 本机安装指引

先读 [README](../../../README.md)、[当前开发状态](../../../PROJECT_STATUS.md)与[安装说明](../../../docs/installation.md)。只安装到用户指定项目，使用固定版本 install.ps1；不注册到用户全局，不接管已有私人 PAA。

面向使用者，检查 Windows、Python、Codex、Eagle 与已有 PAA，确认资料目录和本次许可。安装至少必须问：

> 项目附带一批作者／个人审美观点，可提供不同创作取舍的参考。它们不是统一标准，也不代表你的喜好。你希望保留并启用这些内容，还是只使用基础技巧？

未收到明确回答，不导入或读取可选观点，不代选；可以继续无关环境检查。选择保留才启用 optional-aesthetics，拒绝则卡库、预读汇编、关键词/语义检索和按 ID 读取均应排除它。记录选择，升级不得改回；用户自建卡与包管理的种子卡分清。源目录存在不代表运行启用。

使用者自己的偏好资料是可选项，不用项目作者或其他讲者的观点填充。图片向量预处理和新增付费调用需说明数据范围并得到本次许可；不继承示例中的预算或凭据。

按实际可用实现推进，使用隔离测试数据验证。工具、图片展示和同 ID 追问分别验收，不能用独立进程成功替代实际 Codex 客户端。发现另一套 PAA 或全局配置冲突时保留原状并解释；开发任务不得为完成验收而接管原实例。

使用 install.ps1 -Project <指定目录>；-Aesthetics enable/disable 只能表达已收到的明确答复。省略时首次记录 unanswered，仅基础技巧，升级沿用原选择。本版没有附带第三方观点卡，应说明此事实。开发验收使用合成选项，不记作当前用户偏好。

安装资源在目标 .agents/skills/paa-public，MCP 在目标 .codex/config.toml 的 paa_public。中断用 recover 续接；有后续修改冲突则停止并保护内容。卸载使用同一入口 -Action uninstall，默认保留数据。不能因安装请求自动开启云端、付费调用或发布。
